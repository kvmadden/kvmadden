### Kevin Madden, PharmD

Pharmacist and pharmacy leader who designs and builds software. I start from a problem I've seen in the field, build it end to end, measure it, and publish where it falls short.

**All projects:** [kvmadden.com/projects](https://kvmadden.com/projects)

**AI platform work**
- [jargon](https://github.com/kvmadden/jargon): AI explanations that must pass a second-model check, plus an offline eval of that check. It found the verifier accepted 5 wrong outputs in 78 (6.4%).
- [pii-redaction-gate](https://github.com/kvmadden/pii-redaction-gate): fail-closed PII redaction for free text and clinical-style notes, measured on 182 labeled synthetic snippets with every miss published.
- [knowledge-mcp](https://github.com/kvmadden/knowledge-mcp): an MCP server for shared agent memory where every write passes one screening gate, locked by a 324-case test over the whole tool registry.
- [local-model-workshop](https://github.com/kvmadden/local-model-workshop): pick, test and chain small self-hosted models, with a reproducible comparison.

**Clinical content with release gates**
- [counter-intelligence-sim](https://github.com/kvmadden/counter-intelligence-sim): vaccine conversation practice where the build fails on any clinical claim without a CDC source and a review stamp. [Play](https://counter-intelligence.vercel.app)
- [vax-or-fiction-game](https://github.com/kvmadden/vax-or-fiction-game): a room game for talking through immunizations, built on a sourced question bank.

**Agent tooling**
- [operator-skills](https://github.com/kvmadden/operator-skills): Claude Code skills that name common agent failures and prescribe a correction.

Most of my other work is private because it's built around real teams. All data in public code and demos is fictional or synthetic.
