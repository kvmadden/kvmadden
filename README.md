### Kevin Madden, PharmD

Pharmacist and healthcare leader who designs AI tools for clinical work and tests where they fail.

**Selected work**

- [Clinical evidence map](https://kvmadden.com/projects/clinical-evidence-map/): a review desk for faxed prior-authorization packets. 73 of 120 blind calls settled without a reviewer, with no silent errors.
- [Redaction gate](https://kvmadden.com/projects/pii-redaction-gate/): strips identifiers from clinical text before it reaches a model. It left 12 of 2,577 identifiers in documents it marked clean.
- [jargon](https://kvmadden.com/projects/jargon/): a learning app whose AI checker I tested as a pharmacist. It approved at least 5 explanations that were wrong.
- [knowledge-mcp](https://kvmadden.com/projects/knowledge-mcp/): agent memory with one screening gate on every write. None of 324 planted values reached storage.
- [Counter Intelligence](https://kvmadden.com/projects/counter-intelligence-sim/): a branching game for practicing vaccine conversations. All 24 clinical claims cite a public-health source.
- [Vax or Fiction](https://kvmadden.com/projects/vax-or-fiction-game/): a room game for talking through immunizations. All 144 questions show a public source.
